# Desmistificando a Bipolaridade

Jornada interativa de psicoeducação sobre Transtorno Bipolar, concebida para acesso público e uso prioritário em celular.

## Publicação no GitHub Pages

1. Abra **Settings** do repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/(root)**.
5. Clique em **Save**.

Após a publicação, o endereço esperado é:

https://zendevguru.github.io/desmistificando-a-bipolaridade/

## Observação

O conteúdo é educativo e deve passar por revisão da supervisão clínica antes da divulgação institucional definitiva.
